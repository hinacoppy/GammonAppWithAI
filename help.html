Backgammon vs AI

◆このアプリは何？

コンピュータ(AI)を相手にバックギャモンが遊べるアプリです。
AI には、バックギャモンAIエンジン wildbg を使っています。エンジンはブラウザの中で動くため、サーバーとの通信は必要ありません。

◆何ができるの？

バックギャモンが遊びたい！でも対戦相手がいない！ といった状況のときに、AI と気軽に対戦できます。
あなたは常に画面の下側の駒(黒)、AI は上側の駒(白)を持ちます。
スマートフォンでも動きますが、画面が小さいため、タブレットの使用をお勧めします。
人vs人の対戦機能や、世界中の人と対戦する機能はありません。

●主な機能
・Opening Roll で先手後手を決め、AI とゲームを進めます。AI もダブル、テイク/パス(ドロップ)の判断をします。
・マッチゲーム(1～7pt)と、Unlimited Game に対応しています。Unlimited Game では Jacoby ルールが使えます。
・ポイントのタップでそのポイントにある駒を動かせます。ダイスの大きい目から使います。
・ワンクリックでブロックポイントを作れます。GalaxyやHeroesと同じ動きです。
・棋譜出力機能があります。ゲームの棋譜をダウンロードして解析ツールに掛けることにより、エラー解析ができます。

◆どうやって使うの？

まずは「全画面表示のアプリとして使う」の手順に従ってホーム画面に登録してください。
ホーム画面に登録されたアイコンをタップすればアプリが立ち上がります。
AI の準備ができるまで、画面に「AI loading...」と表示されます。表示が消えたら対戦開始です。

(1)[Opening Roll] をタップして、先手を決めます。(ダイスの目の大きい方が先手です)
(2)自分の手番では、ダイスの目に従って駒をドラッグして動かします。駒やポイントをタップして動かすこともできます。
(3)動かし終わったら [Done] をタップして手番を AI に渡します。(自分側のダイスをタップしても同じです)
 →間違えたときは [Undo] で動かす前に戻せます。
(4)AI の手番では、AI が自動でロール(またはダブル)して駒を動かします。
(5)自分の手番のロール前には [Double] か [Roll] を選べます。クローズアウトされているときは、[Roll] の代わりに [Pass] が表示されます。
(6)AI からダブルされたときは、[Take] か [Pass] を選びます。
(7)ゲームが終わると結果が表示されます。[Next] で次のゲームに進みます。(マッチに決着がついたときは [OK] が表示されます)

ボタンの意味は直観的になるように心掛けていますので、すぐに理解できると思います。

◆駒の動かし方

●ドラッグ
 駒をつかんで、動かしたいポイントにドロップします。動かせない場所にドロップしたときは元の位置に戻ります。
 [Flash movable Pt] が ON のときは、ドロップ位置が前後1ポイントの範囲であれば動かせるポイントとみなします。
●駒のタップ
 同じ位置で離す(タップする)と、ダイスの目を使って動かせるポイントに動かします。大きい目から使います。
●空きポイントやブロットのタップ
 そこに向かって動かせる駒が2枚あれば、ダイスの2つの目を使って一度にブロックポイントを作ります。
●相手の駒のタップ
 相手の駒があるポイントをタップしても、ブロックポイントを作る操作になります。

◆設定項目には何があるの？

[ Settings] をタップすると設定画面が表示されます。

[Match Length] マッチポイント数を設定できます。$ にすると Unlimited Game になります。

[Show pip] ピップカウントの表示/非表示を切り替えます。
[Jacoby Rule] Jacoby ルールを有効にします。センターキューブのままではギャモン勝ち、バックギャモン勝ちを認めないというルールです。
 →Unlimited Game のみのルールです。マッチゲームでは適用しません。
[Flash movable Pt] ダイスの目に従って動かせるポイントを光らせます。
 →この機能が OFF のときは、掴んだ駒より前であれば動かせます。(イリーガルムーブができるようになります)

[ New Game] 設定内容が反映され、スコアはリセットされます。
[ Cancel] 何も設定せずに設定画面を閉じます。
[ Kifu] MAT形式の棋譜を出力(ダウンロード)します。
[ Help] ヘルプ画面(この画面)が表示されます。
 →ヘルプ画面は別画面で開いていますので、アプリに戻るには画面を閉じてください。

[ Resign] 手番側が負けを宣言します。
 →単純なロジックで「シングル負け、ギャモン負け、バックギャモン負け」を判定しています。
  →一枚でも上がっていれば、シングル負け。
  →一枚も上がっていなくてコンタクトがあれば、バックギャモン負け。
  →コンタクトがなくても、相手のインナーボード(24pt～19pt)に自駒があれば、バックギャモン負け。(たとえ相手が1枚も上がっていなくても)
  →そうでなければ、ギャモン負け。(たとえ次ロールで1枚以上上がれるとしても)

◆まだ実装できていない機能や Known Bugs   m(_ _)m

・使える目があれば必ず使う、というルールが厳格すぎて、下記のような状況になることがある。
  →例えばベアオフ状態で 4pt に一枚だけ残った時 41 の目で4でベアオフできない。1の目を先に使わなければならない。。
   →大局には影響がないと思いますので、そのままとさせてください。m(_ _)m
・AI の強さは変更できません。また、AI の準備(読み込み)に少し時間が掛かることがあります。
・クロック(持ち時間)の機能はありません。
・レイアウトデザインが中途半端。色デザインがイマイチ。
 →アプリの機能的には問題ではないため、気にしないことにします。

◆全画面表示のアプリとして使うには？

Webアプリとして実装していますので、インストールしてもスマホの容量を消費しません。
「ホーム画面に追加」の機能を使うことにより、普通のアプリと同じように全画面表示のアプリとして使うことができます。

●Android端末の場合
(1)Chromeでこのアプリを開く
(2)設定(右上の３点)を開き、「ホーム画面に追加」をタップ
(3)ホーム画面に追加してもよいかどうかの確認画面で「追加」をタップ
(4)ホーム画面に追加しましたのメッセージが表示されるので、画面内を確認
(5)次回からはこのアイコンをタップすればアプリが開く

●Apple端末(iPhone, iPadなど)の場合
(1)Safariでこのアプリを開く
(2)送信アイコン(□から↑が突き出ているアイコン)をタップ
(3)「ホーム画面に追加」をタップ
(4)「追加」をタップ
(5)追加されているはずなので、画面内を確認
(6)次回からはこのアイコンをタップすればアプリが開く

それぞれの端末の標準ブラウザでなければ「ホーム画面に追加」機能が使えません。ご注意ください。
一度起動してしまえば、AI を含めてネットワークアクセスはありません。

◆その他

バグ報告や機能拡張要望は kawakami あっと js4.so-net.ne.jp まで。対応するかどうかは確約できませんが。。
